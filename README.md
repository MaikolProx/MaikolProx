## Lo Que Construyo

### [hybrid-rag-evals](https://github.com/MaikolProx/hybrid-rag-evals) — RAG en Producción con Métricas Reales
Pipeline completo de retrieval híbrido: BM25 + embeddings densos + fusión RRF + reranking cross-encoder. Incluye un framework completo de evaluación con recall@k, MRR, NDCG y métricas de fidelidad — todo implementado desde cero sin wrappers.

**Resultados**: Recall@5: 0.643 → 0.964 (+49.8%) con reranking. 23 tests pasando, 93.27% de cobertura.

`Python` `BM25` `Sentence-Transformers` `RRF` `Cross-Encoder` `Evaluación`
