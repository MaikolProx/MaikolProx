# Miguel Hernandez — Webs a medida, IA y automatización

Construyo sitios web a medida para negocios de Latinoamérica (inmobiliarias, clínicas, restaurantes) y sistemas de IA que funcionan en producción, no solo en demos.

## Qué hago

**Webs y landings**: rápidas, adaptadas a móvil, con aviso legal, privacidad y cookies, SEO técnico y botón de WhatsApp. Cada entrega pasa un checklist de 20 puntos.  
**Experiencias 3D en el navegador**: showrooms inmobiliarios y configuradores con Three.js (en desarrollo).  
**IA aplicada**: RAG híbrido, agentes autónomos y evaluación de LLMs.  
**Seguridad**: auditoría de redes y aplicaciones web.

## Demo

- [Demo de web para inmobiliarias](https://demo-clinicas.pages.dev/inmobiliaria): fichas, calculadora de cuota y solicitud de visita (datos de ejemplo).
